## How to Use

1. Open any `.tap` file to see the TapScript notation
2. Copy it into the TapScript Studio at `http://localhost:5557` to compile and play
3. Use these as reference material for writing your own compositions
4. Try transposing to a different key using the transpose endpoint

## Educational Notes

- Each song uses real chord progressions from the original recording
- Melodies are simplified for educational purposes
- Lyrics included for verse 1 and chorus where applicable
- `@player` lines show suggested instrument arrangements
