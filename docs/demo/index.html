How it reads

Rows are voices

Chords:, Melody: and any @name row play together. Four rows of four bars is one four-bar passage by a band, not sixteen bars in sequence.

Bars divide themselves

You never write durations. | A4 C5 E5 | is three tokens in one bar, so it is a triplet. Six tokens are eighth notes. A bar is one bar long and its contents share it out.

Dots are silence, dashes are chords

. means nothing new starts here. c4-e4-g4 stacks pitches that sound at the same instant. Pitches carry an octave — a bare A is the chord, not the note.

A written time is an arrival time

The idea the rest of the system is built on, and the one thing here with no equivalent elsewhere. A score says “beat three” without saying where beat three happens — at the player's hands, at the instrument, or at the ear it was written for.

Declare a stage and TapScript reads written times as the moment sound should arrive, then solves backwards for when each player must move. An organ 14 m away, whose pipe takes 140 ms to speak, has to be played 241 ms early to land on the beat.

[Stage]
listener: conductor
@timpani: pos 4,-9  | speech: percussion
@organ:   pos 0,-14 | speech: organ-large

  voice    distance  travel  act
  timpani  9.8 m     29 ms   -30 ms
  organ    14.0 m    41 ms   -241 ms

  spread at the podium   0 ms
  spread at organ's desk  non-zero

Which is why an orchestra watches the conductor rather than listening to each other. The eyes carry intention; the ears only carry history. Solving stages needs the full compiler — this page compiles notation, not rooms.

Take it further

Install it

pip install tapscript
tapscript new "My Song" -o s.tap
tapscript compile s.tap --play

Python 3.10+. No dependencies at all — the parser, the MIDI writer and the synthesiser are standard library only.

What this page leaves out

The browser engine is a faithful subset, checked note-for-note against the reference compiler. The full version adds the stage solver, a soundfont renderer, several thousand chord charts, an embedded agent, and an MCP server so any number of agents can write one score at once.
