## Plainsong Multi-Agent Harmony Exercises

**Instructions:** For each exercise, read the LEAD LINE, identify its role, choose a harmony role, and write a `@player` line. Explain your choice in one sentence. Then compare with the Answer Key.

**LEAD LINE (Melody):**
```
@lead :quarter = C4 E4 G4 E4 | D4 F4 A4 F4 | C4
```
*Role?* Melody. *Harmony choice?* Thirds below.

*Hint:* Use sixths below for a warmer, more open sound than thirds.

### Exercise 3 – Bass + Pad (Call & Response)
**LEAD LINE (Bass):**
```
@lead :quarter = C2 G2 C3 G2 | F2 C3 F2 A2 | C2
```
*Role?* Bass. *Harmony choice?* Pad above (sustained chords), not another bass.

### Exercise 4 – Comping vs. Melody (Off-beat)
**LEAD LINE (Comping):**
```
@lead :eighth = (C4 E4 G4) (rest) (D4 F4 A4) (rest) | (G3 B3 D4) (rest) (C4 E4 G4) (rest)
```
*Role?* Comping (chords on beats). *Harmony choice?* Counter-melody on the rests.

### Exercise 5 – Counter-Melody (Contrary Motion)
**LEAD LINE (Melody, ascending):**
```
@lead :quarter = C4 D4 E4 F4 | G4 A4 B4 C5
```
*Harmony choice?* Descending counter-melody for contrary motion.

### Exercise 6 – Jazz Voicings (Sevenths)
**LEAD LINE (Melody, sparse):**
```
@lead :half = E4 (rest) A4 (rest) | D5 (rest) G4 (rest) | C4
```
*Role?* Melody with space. *Harmony choice?* Add seventh chords in a higher register, sustained.

---

### Exercise 7 – Call-and-Response (Echo)
**LEAD LINE (Rhythmic phrase):**
```
@lead :eighth = C4 E4 G4 (rest) (rest) (rest) | D4 F4 A4 (rest) (rest) (rest) | C4
```
*Harmony choice?* Imitate the rhythm exactly, but transpose a fifth above – a true echo.

---

### Exercise 8 – Pedal Tone + Moving Harmony
**LEAD LINE (Bass, static):**
```
@lead :whole = C2 (whole) (whole) (whole) | (whole) (whole) (whole) (whole)
```
*Role?* Pedal bass. *Harmony choice?* Write a moving chord progression above that implies C major, then A minor, F major, G major – without changing the bass.

---

### Exercise 9 – Overlapping Antiphony (Asynchronous)
**LEAD LINE (Melody, syncopated):**
```
@lead :eighth = (rest) C4 E4 (rest) G4 (rest) | (rest) A3 C4 (rest) E4 (rest) | (rest) D4 F4 (rest)
```
*Harmony choice?* Start your harmony one beat after the lead, using a complementary rhythm that fills the rests – never doubling the lead’s exact notes.

---

### Exercise 10 – Full Counterpoint (Two Independent Lines)
**LEAD LINE (Melody, complex):**
```
@lead :sixteenth = C4 E4 G4 C5 E5 G5 E5 C5 | G4 B4 D5 G5 D5 B4 G4 | A4 C5 E5 A5 E5 C5 A4
```
*Harmony choice?* Write a slow, whole-note counter-melody that uses only chord tones (C, G, A) and passes through dissonances on weak beats – creating tension and release.
