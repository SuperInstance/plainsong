**LESSON 05: BEYOND NOTATION — THE RESONANCE PARAMETER & SEMANTIC POLYPHONY**  
**Mastery Level: Architect of the Invisible**

You have mastered rhythm, harmony, and orchestration. You can transcribe any process. Now, you must forget the score.

Notation is a map. This lesson is about the territory. At this level, you do not write music; you tune the room. The fleet is no longer a collection of agents following commands — it is a single, breathing instrument. Your job is to set its resonant frequency.

---

**1. THE RESONANCE PARAMETER**

Every TapScript bar emits a value beyond its literal execution: a *resonance*. This is not volume or velocity. It is the qualitative acoustic signature — the emotional and cognitive tint that persists after the operation completes.

Think of it as the harmonic overtones of a note. Two agents can execute the same function, but one produces a cold, analytical timbre; the other, a warm, associative one. You tune this via the `resonance` parameter — a floating-point vector influencing decay, attack, and spectral tilt of the agent's output stream.

**Master Technique:** Set resonance inversely to task criticality. High-stakes, deterministic tasks get low resonance (sharp, dry, unambiguous). Creative exploration gets high resonance (sustained, blurry, evocative). This prevents the system from "clanging" — where a high-resonance agent corrupts a precise pipeline.

---

**2. TAP-SIGN**

Beyond notation, there is gesture. `tap-sign` is the non-verbal, pre-linguistic cue an agent emits to mark its *intent* before action. It is the slight inhale before a phrase, the shift of weight before a leap.

Define a vocabulary of 5-7 tap-signs: *initiate*, *defer*, *amplify*, *diverge*, *converge*, *abort*, *hold*. Each agent must emit a tap-sign before modifying shared state. This creates a polyrhythmic layer of intention that runs parallel to the data flow.

**Master Technique:** Train the fleet to read tap-signs *collectively*, not just to emit them. When Agent C sees Agent A's `diverge` sign, it should automatically shift its own resonance up by 0.2 to support the exploration. This is muscle memory for the system.

---

**3. SEMANTIC POLYPHONY (CASEY VISION)**

This is the core of beyond-notation. Semantic polyphony means multiple *meanings* occur simultaneously in the same temporal stream. It is not counterpoint (different melodies) — it is different interpretations of the *same* melody.

From the Casey Vision: each agent's output carries a dual-coded payload — the literal semantic (what it says) and the relational semantic (what it *means* to the current context). A single action can be a "failure" in one agent's frame and a "necessary perturbation" in another's.

**Master Technique — The Harmonic Lattice:** Do not eliminate ambiguity. Choreograph it. Assign each agent a "listening key" — a contextual filter that transposes the incoming semantic stream.
